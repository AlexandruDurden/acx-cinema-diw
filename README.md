# Práctica - ACX Cinema

* **Autor:** Alexandru Sorin Preda Baltac
* **Asignatura:** DIW
* **Práctica:** P3.1 Proyecto Final Responsive Sass

## Descripción
Página web de cine (ACX Cinema) maquetada con HTML, SASS y Vite.

## Instrucciones de ejecución
1. Instalar dependencias: `npm install`
2. Arrancar en desarrollo: `npm run dev`
3. Compilar para producción: `npm run build`
